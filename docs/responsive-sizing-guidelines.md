# レスポンシブ時のサイズ設計指示書

このドキュメントは、Each Spirit の各ページを実装・修正する際のサイズ、余白、コンテナ、カード配置の基準です。デザイン装飾の指示ではなく、読みやすさと画面幅の使い方を統一するための実装ルールです。

## 基本方針

モバイルでは、中央寄せの狭いカードを重ねない。画面幅を有効に使い、外枠、内枠、カードの多重構造を減らす。PCでは情報量を増やし、横幅を広く使って比較・一覧しやすくする。

## ブレイクポイント

- `base`: 〜639px。スマートフォン前提。
- `sm`: 640px〜。大きめスマホ、縦タブレット。
- `md`: 768px〜。タブレット、2カラム開始候補。
- `lg`: 1024px〜。PCレイアウト開始。
- `xl`: 1280px〜。サイド導線や広告枠を置ける幅。

## ページ幅

- モバイルのページ左右余白は `16px` を基本にする。
- 390px 幅では、主要コンテンツ幅を最低 `calc(100% - 32px)` 確保する。
- `section-shell` 相当の共通コンテナは、モバイルで `width: calc(100% - 24px)` まで狭めてもよいが、カード内にさらに大きい padding を重ねない。
- PCは `min(1360px, calc(100% - 40px))` を基準にし、比較ページや一覧ページは広く使う。

## モバイルのカードルール

- モバイルで「ページ枠 + セクション枠 + カード枠」の3重囲いを作らない。
- 主要セクションの外側カードは、モバイルでは `border` と `shadow` を弱めるか外す。
- カード内 padding はモバイルで `16px`、PCで `20〜32px` を目安にする。
- カード同士の縦間隔は `12〜16px`。大きすぎる余白でスクロール量を増やさない。
- 画像付きカードは `aspect-ratio: 16 / 9` または `4 / 3` を固定し、画像読み込みで高さが揺れないようにする。

## セクション余白

- モバイルのセクション上下 padding は `28〜36px`。
- PCのセクション上下 padding は `48〜72px`。
- 見出し直下の説明文は `margin-top: 12〜16px`。
- セクション間で背景色やカード枠を毎回変えすぎない。読み進める負担を増やさない。

## タイポグラフィ

- モバイルの `h1` は `28〜36px`、行間は `1.12〜1.2`。
- モバイルの `h2` は `22〜28px`。
- カード内見出しは `18〜22px`。
- 本文は `14〜16px`、行間は `1.75〜2.0`。
- ボタン、バッジ、ステータス表示の文字は `12〜14px`。長文を詰め込まない。
- viewport 幅に比例したフォントサイズは使わない。`clamp()` を使う場合も上限・下限を明確にする。

## レイアウト切り替え

- モバイルでは基本1カラム。
- `md` 以上で2カラム、`lg` 以上で3カラムを検討する。
- 3カラムカードは、モバイルで1カラム、タブレットで2カラム、PCで3カラムにする。
- サイドバー、広告枠、補助導線は `xl` 以上で表示する。モバイルでは本文の後ろに移動するか非表示にする。

## ヘッダーとナビ

- モバイルのヘッダーは高さを抑え、ロゴ行とカテゴリナビの余白を小さくする。
- 横スクロールナビは許可するが、左右に十分な見切れ余白を入れ、現在位置が分かるようにする。
- ナビのボタンは高さ `36〜40px`、左右 padding `12〜16px` を目安にする。

## プロフィール・運営者ページ

- モバイルではプロフィールカードを横幅いっぱいに近づけ、カード内の情報を縦に並べる。
- アイコン画像は `72〜96px` の固定枠。本文幅を圧迫する場合は、画像と名前を横並び、詳細ステータスは下に置く。
- 自己紹介は長文段落ではなく、`担当`、`得意`、`調査スタイル`、`一言` のような短いステータス行で表示する。
- 挨拶やコメント枠は1カード1つまで。コメントの中にさらに枠を重ねない。

## フォーム

- モバイルでは全入力を1カラムにする。
- input、select、textarea の高さは最低 `44px`。
- フォーム項目間は `16px`。
- エラー文は入力欄の直下に置き、ページ上部だけにまとめない。
- 送信ボタンはモバイルで横幅いっぱい、PCで内容幅または `240px` 程度を許可する。

## 実装チェック

実装後は以下を確認する。

- 390px 幅で本文が狭くなりすぎていない。
- 画面内に外枠が何重にも見えていない。
- 横スクロールが本文全体に発生していない。
- ボタンやバッジ内の文字が折れすぎていない。
- カード内カードが連続していない。
- ファーストビューで主要見出しと次の内容の一部が見えている。
- PCでは余白が余りすぎず、一覧・比較・サイド導線に使えている。
