# Each Spirit — AI画像生成プロンプト集

生成した画像は `public/images/categories/<category>/` に配置してください。
ファイル名は各プロンプトのキー名（例: `hero.jpg`、`cta.jpg`）と一致させてください。

**共通スタイル指示（全プロンプトに付加推奨）:**
```
photorealistic, editorial photography, natural lighting, high resolution, Japanese aesthetic, cinematic composition, no text, no watermark
```

## 推奨ツール

- **Midjourney v6+**: 高品質写真リアリズム。`--style raw` でよりナチュラルに
- **DALL-E 3**: OpenAI API経由で一括生成に便利
- **Stable Diffusion XL**: ローカル生成・カスタマイズに
- **Adobe Firefly**: 商用利用に安全、日本語プロンプト可

## 注意事項

- 人物が映る画像は顔が識別できない構図（シルエット・後ろ姿・遠景）を推奨
- 著作権フリー素材として生成した画像のみ使用すること
- 生成後は `public/images/` に配置するだけで自動的にサイトに反映されます（コード変更不要）
