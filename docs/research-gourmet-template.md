# グルメカテゴリ 調査指示テンプレート（飲食店・グルメ系）

## このドキュメントの目的

このテンプレートは、**調査エージェントへの依頼書**として使います。

調査エージェントが収集・整理したデータをもとに、**別のページ実装エージェント（Claude Code）が総合的な情報サイトへの反映作業を行います**。そのため、調査エージェントはコードを書く必要はありません。情報を正確に・もれなく・読みやすい形式でまとめることに集中してください。

**使い方**: `[PLACEHOLDER]` と書かれた箇所を実行時に書き換えて依頼してください。

---

## 依頼概要

- **調査カテゴリ**: `[CATEGORY]`（例: カフェ、ラーメン、居酒屋、パン屋）
- **調査対象県**: `[PREFECTURE]`（例: 新潟県、滋賀県、仙台市）
- **調査日**: `[COLLECTED_AT]`（例: 2026-06-09）

---

## 調査の目的と使われ方

収集したデータは以下の用途で使われます。ページ実装エージェントがこのデータを読み取って、Next.js のウェブサイトに反映します。

| 使われ方 | 対応するデータ |
|---------|-------------|
| 店舗詳細ページ | 各店舗の基本情報・特徴・FAQ・出典 |
| ランキングページ | ランキング構成・評価スコア・選定理由 |
| リージョン一覧ページ | 県の紹介文・SEOテキスト・おすすめ店 |
| 検索・サイトマップ | タグ・slug・カテゴリ分類 |

---

## 調査スコープ

| 項目 | 基準 |
|------|------|
| 店舗数 | **15店舗~**（県を代表する主要エリアを網羅） |
| スタイルの多様性 | 最低4種以上の異なる業態・スタイルを含む |
| エリアの多様性 | 県庁所在地、観光地・地方など関係なく分散 |
| 老舗〜新店バランス | 老舗（創業10年以上）を少なくとも2店含む |
| ランキング数 | **4本以上**（総合1本 + テーマ別3本以上） |

---

## 調査先（優先度順）

1. **公式サイト** — 営業時間・住所・メニュー・価格の一次情報として最優先
2. **食べログ** — 口コミ評点・営業情報の裏付け
3. **観光公式サイト** — 県・市の観光サイト
4. **地元メディア** — 地元タウン誌・地方新聞
5. **Instagram** — 不定休の店舗の最新営業情報・雰囲気確認
6. **じゃらん / るるぶ** — 観光ガイド掲載確認

## アウトプット形式

Markdown で出力してください。コードは不要です。

### ファイル構成（どちらでも可）

あなたの特性や得意な操作に合わせて選んでください。

**案A：3ファイル分割で一つのフォルダにまとめる**
```
[region]-overview.md   ← セクション1（リージョン概要）
[region]-shops.md      ← セクション2（全店舗データ）
[region]-rankings.md   ← セクション3（全ランキング構成）
```

**案B：1ファイルにまとめる**

```
[region]-research.md   ← セクション1〜3すべてを1ファイルに
```

どちらの形式でも、後続の実装エージェント（Claude CodeなどのAI）が読み取れる内容であれば問題ありません。セクション構造とフォーマットを守ることが最優先です。

## 調査時の注意事項

- **実在確認**: 調査時点で実際に営業していることを確認してください
- **不定休の店舗**: 営業時間・定休日に「要確認（公式Instagram参照）」と明記してください
- **公式サイトがない店舗**: SNS・食べログのURLを代わりに記載してください
- **PR・広告掲載なし**: 全店舗はPRなし・自然な評価で選定してください
- **日本語で記述**: 店舗名・説明文・FAQ はすべて日本語で記述してください
- **slug は英語 kebab-case**: `chamonix-niigata` のように英数字・ハイフンのみ使用
