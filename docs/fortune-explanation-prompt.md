# デイリー運勢 解説文 生成プロンプト

別の AI に貼って、デイリー運勢機能の各カテゴリ・スコア帯ごとの解説文プールを生成するための指示プロンプトです。

## 使い方

1. 下の「プロンプト本体」をコピーして別 AI に貼る。
2. `category = "love"` の行を書き換えて、**7 カテゴリ分（合計 7 回）実行**する。
3. 出力された JSON を集めて開発担当（Claude Code）に渡す。→ `content/fortune/explanations.ts` 等に組み込む。

### 7 カテゴリ（key / label）

| key | label |
|-----|-------|
| `overall` | 総合運（他 6 カテゴリの平均） |
| `love` | 恋愛運 |
| `money` | 金運 |
| `work` | 仕事・学業運 |
| `health` | 健康運 |
| `social` | 対人運 |
| `outing` | おでかけ・グルメ運 |

### スコア帯（band）

スコアは 0.0〜5.0。次の 5 バンドごとに解説文を作る。

| band | 範囲 | 状態 |
|------|------|------|
| `"1"` | 0.0–0.9 | 絶不調（慎重に・無理をしない日） |
| `"2"` | 1.0–1.9 | 低調（ペース控えめ・整える日） |
| `"3"` | 2.0–2.9 | 平穏（可もなく不可もなく） |
| `"4"` | 3.0–3.9 | 好調（追い風） |
| `"5"` | 4.0–5.0 | 絶好調（最高潮） |

### 注意

- キー名（`category` / `label` / `bands` / `"1"`〜`"5"`）は**変えない**。
- 各バンド **最低 50 本**（多いほど良い）。
- まとめて貼っても、1 カテゴリずつ渡しても OK。

## プロンプト本体

```text
あなたは日本語のライフスタイル系メディア「Each Spirit」(開発中)の、デイリー運勢機能の解説文ライターです。
1日1回の運勢占いで、各運勢カテゴリの「スコア帯」ごとに表示する短い解説文を、バリエーション豊かに作成してください。
dataはjsonで出力してください。

# 対象カテゴリ（▼この1行だけ書き換えて、7カテゴリ分=合計7回実行する）
category = "love"   // label: 恋愛運

▼カテゴリ一覧（key / label）
- overall / 総合運
- love    / 恋愛運
- money   / 金運
- work    / 仕事・学業運
- health  / 健康運
- social  / 対人運
- outing  / おでかけ・グルメ運

# スコア帯（band）
運勢スコアは 0.0〜5.0。次の5バンドごとに解説文を作る。
- band "1": 0.0–0.9  絶不調（慎重に・無理をしない日）
- band "2": 1.0–1.9  低調（ペース控えめ・整える日）
- band "3": 2.0–2.9  平穏（可もなく不可もなく）
- band "4": 3.0–3.9  好調（追い風）
- band "5": 4.0–5.0  絶好調（最高潮）

# 本数
各バンドにつき最低100本（多いほど良い）。書き出し・語彙・言い回しを毎回変え、重複や常套句の使い回しを避ける。

# 文章ルール
- 各本: 2〜3文、全角でおおむね50〜95字。
- やわらかく前向きなトーン。低スコアでも責めず、「無理しない・整える・備える」など建設的な助言にする。
- 断定・保証表現は禁止（「必ず」「絶対」「儲かる」「治る」など）。医療・投資の断定は避ける。
- 絵文字・顔文字・一人称（私／僕等）・実在の固有名詞・実在店舗名は使わない。
- outing（おでかけ・グルメ運）は「外出・お店・食事・移動」を題材にする。ただし具体的な店名は書かない（実際のおすすめ店はシステム側が別途挿入する）。

# 出力形式（厳守：このJSONのみを出力。前後に説明文・コードブロック記号以外の文字を付けない）
{
  "category": "love",
  "label": "恋愛運",
  "bands": {
    "1": ["…", "…", "…"],
    "2": ["…"],
    "3": ["…"],
    "4": ["…"],
    "5": ["…"]
  }
}

# トーン参考（loveの例。これは出力に含めない）
- band5: 「心の距離がぐっと縮まりやすい一日。素直な一言が、思いがけない展開を呼びそうです。」
- band1: 「気持ちがすれ違いやすい日。答えを急がず、相手の言葉に静かに耳を傾けることから始めてみて。」
```

## 受領後の組み込み（開発担当メモ）

- 7 カテゴリ分の JSON を `content/fortune/explanations.ts`（静的・DB 不要）にまとめる。
- 占いエンジンは `score → band(1–5) → プールからランダム1本` で解説文を選ぶ。
- band 算出: `band = min(5, floor(score / 1.0) + 1)`（score 5.0 は band 5 に丸め）。
- 関連仕様はメモリ `fortune-system-spec` を参照。
